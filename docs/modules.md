# Modules Metier

Cette page liste les modules que EGest peut progressivement integrer.

## Modules prioritaires

### Authentification

- Connexion.
- Deconnexion.
- Session utilisateur.
- Mot de passe securise.

### Utilisateurs

- Creation d'utilisateurs.
- Modification de profils.
- Activation ou desactivation de comptes.
- Attribution de roles.

### Roles et permissions

- Administrateur.
- Gestionnaire.
- Utilisateur simple.
- Permissions par module.

### Tableau de bord

- Indicateurs principaux.
- Alertes.
- Activite recente.
- Acces rapide aux actions importantes.

## Modules metier possibles

### Clients

- Liste des clients.
- Fiche client.
- Historique.
- Recherche et filtres.

### Produits ou services

- Catalogue.
- Prix.
- Disponibilite.
- Categories.

### Facturation

- Creation de factures.
- Statuts.
- Paiements.
- Export PDF.

### Rapports

- Rapports periodiques.
- Export Excel.
- Statistiques.

### Parametres

- Informations de l'organisation.
- Preferences de l'application.
- Configuration des exports.

## Priorisation recommandee

1. Authentification.
2. Utilisateurs et roles.
3. Tableau de bord.
4. Premier module metier principal.
5. Exports et rapports.
