# Roadmap

Cette roadmap sert de guide pour faire evoluer EGest progressivement.

## Phase 1 - Fondation

- Structure backend et frontend.
- README et documentation initiale.
- Tests de demarrage.
- Endpoint `/health`.
- Fenetre desktop minimale.

Etat : en cours.

## Phase 2 - Configuration

- Configuration centralisee du backend.
- Variables d'environnement.
- Fichier `.env.example`.
- Configuration du client API frontend.

## Phase 3 - Base de donnees

- Choix definitif entre SQLite et PostgreSQL pour le developpement.
- Configuration SQLAlchemy.
- Configuration Alembic.
- Premier modele de donnees.
- Premier repository.

## Phase 4 - Authentification

- Modele utilisateur.
- Hashage des mots de passe.
- Route de connexion.
- Gestion de session frontend.
- Protection des routes sensibles.

## Phase 5 - Interface principale

- Fenetre principale complete.
- Sidebar.
- Topbar.
- Statusbar.
- Navigation entre les ecrans.

## Phase 6 - Premier module metier

- Choix du premier module prioritaire.
- Modeles.
- Schemas.
- Routes API.
- Services.
- Ecrans frontend.
- Tests.

## Phase 7 - Exports et rapports

- Export PDF.
- Export Excel.
- Rapports simples.
- Filtres et statistiques.

## Phase 8 - Stabilisation

- Nettoyage du code.
- Tests supplementaires.
- Gestion des erreurs.
- Documentation utilisateur.
- Preparation d'une premiere version.
