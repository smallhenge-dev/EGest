# Vision du Projet

EGest est une application de gestion destinee a centraliser les operations essentielles d'une organisation dans un outil simple, fiable et evolutif.

Le projet repose sur une idee claire : separer l'interface utilisateur, l'API, la logique metier et les donnees afin de pouvoir faire grandir l'application sans la rendre difficile a maintenir.

## Probleme a resoudre

Dans beaucoup de petites et moyennes structures, la gestion repose sur des fichiers disperses, des cahiers, des feuilles Excel ou des outils qui ne communiquent pas entre eux.

EGest vise a proposer une base unique pour suivre, organiser et exploiter ces informations.

## Objectifs produit

- Offrir une interface desktop claire pour les utilisateurs.
- Centraliser les donnees dans une API structuree.
- Faciliter l'ajout de nouveaux modules metier.
- Permettre l'export de donnees vers des formats courants comme PDF ou Excel.
- Preparer une gestion des droits, des roles et des sessions.
- Construire une base professionnelle, testable et maintenable.

## Public cible

EGest peut convenir a :

- Une petite entreprise.
- Une association.
- Un commerce.
- Une equipe administrative.
- Une organisation ayant besoin d'un outil de gestion interne.

## Principes directeurs

- Simplicite avant complexite.
- Code lisible avant abstraction prematuree.
- Separation claire des responsabilites.
- Documentation mise a jour avec le projet.
- Tests pour proteger les fonctionnalites importantes.
